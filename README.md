# Telegram Weather Bot

Погода в Telegram. Написал, потому что надоело открывать сайт погоды: написал городу — получил температуру, ощущается как, ветер, влажность и прогноз на 7 дней. Город запоминается, а подписчикам бот сам присылает погоду каждое утро в 9:00.

Данные — **Open-Meteo**: бесплатный публичный API без ключа и без лимитов для личного использования. Геокодинг городов — их же API.

## Команды

| Команда | Что делает |
|---|---|
| `/weather Москва` | текущая погода |
| `/forecast Москва` | прогноз на 7 дней |
| `/city Москва` | сохранить город по умолчанию (дальше можно просто `/weather`) |
| `/daily` | подписаться на ежедневную рассылку погоды |

## Почему Open-Meteo

Погодные API с ключами (OpenWeather и ко) для учебного проекта — лишняя возня: регистрация, лимиты, секреты в коде. Open-Meteo — без ключа, без регистрации, данные открытые (источник — метеослужбы и NOAA). Для демо и обучения — идеально.

## Как это работает

- геокодер ищет город по названию → координаты;
- прогноз кэшируется на 30 минут (`TTL-кэш` из `utils.py`), чтобы не дёргать API на каждый запрос;
- APScheduler каждое утро в 9:00 рассылает погоду подписчикам (город каждого — из его настроек);
- демо-режим (`WEATHER_DEMO_MODE=1`) отдаёт «выдуманную погоду» с джиттером — для запуска без сети;
- парсинг ответа вынесен в чистые функции `_parse_current` / `_parse_forecast` — их удобно покрывать unit-тестами без моков HTTP.

## Запуск

```bash
python -m venv .venv
pip install -r requirements.txt
export WEATHER_BOT_TOKEN=123456:ABC...   # токен от @BotFather
export WEATHER_DEMO_MODE=1               # 0 — реальный Open-Meteo
python bot.py
```

На Windows — `run_bot7.cmd` (токен из корневого `.env`).

## Из чего состоит

```
bot.py          — команды, рассылка, форматирование сообщений
weather_api.py  — клиент Open-Meteo: геокодинг, текущая погода, прогноз
db.py           — aiosqlite: город по умолчанию, подписки на рассылку
utils.py        — TTL-кэш и retry с джиттером на чистом stdlib
middlewares.py  — троттлинг и логирование
config.py       — настройки из переменных окружения
tests/          — 7 тестов (парсинг текущей погоды, прогноза, кэш, подписки)
```
